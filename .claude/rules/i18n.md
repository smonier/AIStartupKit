# i18n Rules

Auto-loaded when touching locale files or `.properties` resources. Full reference: `.agents/context/jahia-i18n-patterns.md`.

## Two-Tier i18n System

| Tier | Files | Purpose |
|---|---|---|
| CND labels | `settings/resources/<module>.properties` (EN + FR) | Labels for content types, properties, views in jContent editor |
| Front-end UI | `settings/locales/en.json` + `fr.json` | Labels for UI components, actions, dialogs |

**Both tiers are mandatory.** A module that ships CND types must ship both `.properties` files. A module with UI labels must ship both `.json` locale files.

## CND Label Key Conventions

```properties
# Content type label
namespace_MyType.label=My Type Name

# Property label
namespace_MyType.field_name.label=Field Display Name

# Choicelist value
namespace_MyType.field_name.value1=Option One
namespace_MyType.field_name.value2=Option Two

# View label
namespace_MyType.default.label=Default View
namespace_MyType.small.label=Small View
```

## Front-End Locale Key Conventions

```json
{
  "myModule": {
    "actions": {
      "create": "Create Item",
      "delete": "Delete Item"
    },
    "labels": {
      "title": "Title",
      "noResults": "No results found"
    },
    "errors": {
      "notFound": "Item not found"
    }
  }
}
```

## Non-Negotiable Rules

- Every module ships **at minimum EN + FR** — no exceptions.
- Never hardcode display strings in `.tsx` or `.java` files — all user-visible text goes through the i18n system.
- CND property names in `.properties` must exactly match the property names in `definition.cnd`.
- FR translations must be real translations — do not copy EN values as placeholders and ship.
- Use `useTranslation` from `react-i18next` in front-end components (available via `@jahia/javascript-modules-library`).

## File Locations

```
settings/
  resources/
    <module>.properties       # English CND labels (default)
    <module>_fr.properties    # French CND labels
  locales/
    en.json                   # English UI labels
    fr.json                   # French UI labels
```
